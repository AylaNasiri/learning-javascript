# 🎓 Student Score Analyzer

A simple JavaScript project to practice the concepts I have learned so far.

---

## 📌 Project Task

We have a list of student scores:

```js
const scores = [85, 42, 73, 96, 58];
```

The program should check each score and determine the student's result:

| Score Range | Result |
|------------|------------|
| 90 - 100 | Excellent |
| 70 - 89 | Good |
| 50 - 69 | Pass |
| Below 50 | Fail |

After checking all scores, the program should also calculate:

- Average score
- Number of passed students
- Number of failed students

## 🎯 What the Program Should Do

```text
Student Scores
      ↓

      ↓
Determine the result
      ↓
Count passed students
      ↓
Count failed students
      ↓
Calculate the total score
```
