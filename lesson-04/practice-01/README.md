# Lesson 04 - Login System Challenge 🔐

## Overview

In this exercise, I created a simple login system using JavaScript variables and conditional statements.

The goal of this practice was to understand how variables store data and how conditions control the program flow.

---

- String values
- Boolean values
- Conditional statements (if / else)
- Logical comparison
- Console output
