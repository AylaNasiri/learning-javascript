
# Mini Project - Simple Access Checker 🔐

## Overview

In this mini project, I created a simple access control system using JavaScript.

The program checks the user's login status and role, then decides what type of access or message should be displayed.

This project was created to practice:

- Variables
- Boolean values
- Conditional statements
- Logical operators
- Decision making

---

## Project Description

Create a simple access checker with these conditions:

1. If the user is logged in and is an admin:
   - Give full access

2. If the user is only logged in:
   - Show a user welcome message

3. If the user is not logged in:
   - Request login
